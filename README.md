# Supply Chain Efficiency & Inventory Optimization Dashboard

## Project Overview

A Power BI dashboard designed to analyze supply chain performance, inventory levels, replenishment needs, demand forecasting, supplier delivery performance, and fulfillment.

## Tools Used

- Microsoft Power BI
- Power Query
- DAX
- CSV Dataset

## Dashboard Pages

1. Executive Overview
2. Inventory Optimization & Replenishment
3. Fulfillment & Service

## Key Analysis Areas

- Inventory optimization
- Replenishment planning
- Reorder point analysis
- Safety stock
- Demand forecasting
- Supplier delivery performance
- Warehouse performance
- Fulfillment and service levels
